# Pintant components

Teniu un tauler $n \times m$ amb caselles lliures i obstacles. Algunes
caselles lliures contenen una lletra minúscula. Considereu els
components connexos del tauler, suposant adjacències horitzontals i
verticals, però no diagonals. Pinteu els components connexos que
continguin exactament una lletra (potser repetida) amb aquesta lletra, i
els altres components connexos amb punts.

## Entrada

L'entrada consisteix en diversos casos. Cada cas comença amb $n$ i $m$,
seguides d'$n$ files amb $m$ caràcters cadascuna. Les '`X`' indiquen
obstacles, i els punts caselles lliures sense lletra. Podeu suposar que
$n$ i $m$ estan entre 1 i 100.

## Sortida

Escriviu cada tauler amb els components pintats com s'ha indicat
anteriorment, seguit d'una línia en blanc.
